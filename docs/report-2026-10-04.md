## 2. Things you should know (decisions needed)

1. **The website's server runs in the USA.** The live response header shows `fra1::iad1`: the page is served from Frankfurt but the server code, including the contact form that will carry people's names, emails and descriptions of their legal problems, runs in Washington (`iad1`). For a Belgian law firm this should be moved to Europe. In Vercel: project → Settings → Functions → Function Region → Frankfurt (fra1). It is a one-minute change; I have not made it because it changes how the site runs.
2. **Vercel's free "Hobby" plan is meant for personal, non-commercial use.** A law firm's business website normally needs the paid Pro plan. Please check Vercel's current terms before the site goes live on the firm's own domain.
3. **The contact form cannot send yet.** It needs the firm's outgoing mail server. Mail for `orechdin.be` is a POP mailbox at `mailprotect.be`; it is **not** Microsoft 365. The outgoing server must be read from Outlook (Account Settings, server information) or asked from whoever hosts the email. Until then visitors are shown the phone number and email instead, so no enquiry is lost.
4. **Two unused secrets are still stored in Vercel:** `DATABASE_URL` and `BETTER_AUTH_SECRET`. Both belong to the account system that was removed. Recommend deleting both.
5. **The privacy, cookie and legal pages are drafts and are live (hidden from search engines).** They are my earlier drafts, not final texts; the brief says they must not be finalised yet.
6. **Dutch and Hebrew show the English text for now** and say so in their language tag; they are not indexed. Real translations switch on with one setting per language.

## 3. Answers to the brief's developer questions (sections 13 and 14)

Answered from the code and the live site, not from memory.

**Bot / enquiry system**
- There is **no bot**. The earlier assistant (NEO) was removed completely on the firm's instruction, together with the AI services behind it. "Send enquiry" opens the enquiry form on the Contact page.
- The enquiry form is plain: name, email, optional phone, message. No AI, no third-party service, no file upload (documents are to be sent separately to info@orechdin.be, as the notice says).
- Where a submission goes: by email, straight from the website's own server to the office's mail account (once configured). **Nothing is stored** by the website: no database, no dashboard, no CRM. There is no automatic acceptance or rejection; the form only sends a message.
- Protection: input checks in the browser and again on the server, a size limit, a hidden trap field and minimum fill time against spam bots, a limit of 5 messages per visitor per 10 minutes, a same-site check, and protection against header injection. No CAPTCHA service is used, so no US company is involved.
- The server logs only an error code if sending fails, never the message or the sender.

## 5. Go-live checklist (moving www.orechdin.be from Wix to Vercel)

The firm's email must not be disturbed. Mail uses `mx.mailprotect.be` and `mail.orechdin.be`; the domain's DNS is managed at Wix.

1. **Before anything:** decide the Vercel plan (see 2.2), set the function region to Frankfurt (2.1), and finish the mail sending setup (2.3).
2. **In Vercel:** add the domains `www.orechdin.be` and `orechdin.be` to the project. Vercel will list the DNS records it needs.
3. **At Wix (DNS):** change **only** the website records (`www` and the main address) as Vercel instructs. **Do not touch** the mail records: the MX record, the SPF/TXT record, `mail`, or anything mentioning `mailprotect`. Changing those would stop the firm's email.
4. **In Vercel settings, set:** `NEXT_PUBLIC_SITE_URL=https://www.orechdin.be` and `NEXT_PUBLIC_ALLOW_INDEXING=true` (this is what lets Google in), plus the six mail settings. Redeploy.
5. **Make the old site stop competing:** the old Wix pages will disappear when DNS moves; the five old addresses already forward to the new pages.
6. **Test before announcing:** send a real enquiry and confirm it arrives and replying works; try Call, Email and WhatsApp on a phone; open `/en`, `/en/contact`, `/en/privacy`, `/en/cookies`; paste the home link into WhatsApp and check the preview image.
7. **After:** submit `https://www.orechdin.be/sitemap.xml` in Google Search Console; confirm the Privacy, Cookies and Legal notice texts are final before telling people about the site.
